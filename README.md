# 🔥 Dark Ember | Dark Souls 1 Wiki

A web project developed for an **academic competition**, focused on building a wiki-style page about the **Dark Souls 1** universe.

---

## 🏆 Project Context

This project was created as part of a **college competition**, where the goal was to develop a structured, thematic, and functional web application.

The proposal was to build an **interactive wiki** inspired by *Dark Souls*, centralizing relevant content for players.

---

## 📌 About the Project

**Dark Ember** is a website that gathers content about **Dark Souls 1**, acting as a navigation hub with quick access to:

* Bosses
* Lore
* Classes
* Weapons
* NPCs
* Guides
* Covenants
* DLC

The content is accessed through trusted external sources such as YouTube videos and specialized wikis.

---

## 🎮 Theme Choice

**Dark Souls** was chosen due to:

* Strong community
* Rich lore
* High potential for content organization
* Relevance in the gaming industry
